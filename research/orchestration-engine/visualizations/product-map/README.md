# Interactive orchestration insight atlas

This lightweight research prototype provides a shallow atlas with optional vertical depth. It is intended to produce useful discussion, not become an exhaustive documentation product.

## Open the atlas

[Launch the interactive atlas](index.html) in a browser. It is a self-contained HTML, CSS and JavaScript artifact with no server or external assets.

Each perspective answers a different question with a different visual structure:

- Product: what lifecycle and product horizon have actually been built?
- Architecture: where does authority move, and who owns the effect?
- Implementation: how does the visible “Initiate Epic” action become durable execution?
- Experience: what does the user see, what does the product explain, and what remains backstage?

Selecting a concept opens one stronger detail layer. It leads with an interpretation and important relationships. Exact source artifacts and research paths remain collapsed until requested.

## Product-state language

| Status | Meaning in this atlas |
| --- | --- |
| Current product | Part of the stable `9240364` product explanation |
| Emerging capability | Implemented product direction outside the stable snapshot, described by what it changes |
| Conditional connection | Real value whose productive reach or audience is narrower than its visible implementation suggests |
| Retained implementation | Compatibility or historical implementation that is not a current product path |

Lower-level provenance remains available in the research repository rather than becoming a primary atlas category.

## Intended review

The most useful feedback is structural:

- Does each canvas answer its stated question rather than merely inventory components?
- Does selecting a concept reveal a genuine interpretation and useful relationships?
- Is exact evidence available without dominating the explanation?
- Which concept or relationship deserves the next bounded layer of investigation?

The atlas deliberately does not attempt final keep, tune, prune, or architecture recommendations.

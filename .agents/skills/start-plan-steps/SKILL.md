# Start Plan Steps

Instantiate the ready work described by the current Slice Plan.

## Recheck readiness

Before launch, verify the current baseline, dependencies, gates, authority, shared surfaces, and launch register. Refine an unstarted projection when material reality changed. Do not silently broaden a started step.

## Start the ready packet

Create each genuinely ready and independent Plan Step as a separate top-level task through the host harness. Apply the model and reasoning selected in its specification, prompt it to use `run-plan-step`, and supply its fixed specification, repository or worktree route, relevant context, authority, boundaries, acceptance evidence, and this Plan Slice conversation's callback id.

A collaboration subagent is not a Plan Step conversation. Launch each step once, record the evidenced task id and applied profile, and start all independent work in the packet. If launch, profile application, or delivery is not evidenced, keep its status truthful.

Require one proactive completion, blocker, or clarification return. After delivery, continue other available Slice Plan work or end the turn; avoid polling and routine progress ingestion.

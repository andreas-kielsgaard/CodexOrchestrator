# Reasoning Routing

Treat reasoning level as launch metadata when tooling supports it. Do not set a model unless the user explicitly requests one.

Use the smallest reasoning level that matches the destination role's actual uncertainty and risk. Raise reasoning for subtle architecture, conflicting evidence, migrations, security, or ambiguous boundaries—not merely because the wider orchestration is important.

If tooling cannot apply reasoning metadata, record the requested level as requested rather than enforced.

# Context Routing

Route discoveries by audience:

- Direction: changes to objective, sequence, human input, or active ownership.
- Execution: source files, route, acceptance criteria, validation clues, and slice constraints.
- Review and integration: implementation evidence, diffs, validation, and completion details.
- Records: sourced decisions, done/missing state, open items, report links, and refresh cues.
- Suppress: inspected detail that does not affect a future actor.

# Validation Scope

Give executing agents broad clues about where validation belongs in the work sequence. Do not choose their tests, checks, commands, or validation method for them.

For example, independent parallel slices may validate locally while a later integration slice validates the combined state. Keep examples this broad unless a fixed external requirement makes more detail necessary.

Validation guidance never changes implementation scope. Deferring validation does not defer implementation, deliverables, or local acceptance criteria. Record the later owner of deferred validation so the current batch cannot close without it.

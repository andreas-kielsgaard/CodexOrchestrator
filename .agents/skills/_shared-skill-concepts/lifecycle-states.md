# Lifecycle States

Useful workflow states include:

- `ready`
- `launched`
- `waiting-on-worker`
- `waiting-on-review`
- `waiting-on-record`
- `waiting-on-intake`
- `waiting-on-human`
- `waiting-on-tool`
- `settled`
- `paused`

Use explicit states. When human input is required, ask for the concrete decision directly.

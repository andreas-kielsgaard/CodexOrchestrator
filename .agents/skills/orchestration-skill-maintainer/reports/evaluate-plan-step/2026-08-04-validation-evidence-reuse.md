# Validation Evidence Reuse

## Observation and theory

Slice evaluation can turn accepted worker validation into another build cycle when the evaluator is not asked to identify what new evidence a repeated command would add.

## Revision concept

Use returned evidence for its exact committed checkpoint. Add validation only for an uncovered risk, changed material, or explicitly independent reproduction, and state the distinct evidence contributed.

## Evaluation

The evaluator retains full acceptance responsibility while avoiding routine duplicate compilation. Independent verification remains available when it is part of acceptance rather than ceremony.

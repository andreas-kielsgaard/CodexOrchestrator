# Non-actionable partial returns

## Observation

HI-01 emitted 21 partial or checkpoint returns, and sampled SRH-01 work emitted seven partial returns while repeatedly stating that the same task could continue without new authority. CLH-01 later combined a genuine initiation decision with unfinished provenance, adapter safety, validation, and candidate-coherence work. These returns caused parent evaluation, continuation traffic, or premature audit while locally actionable work remained.

## Reader and cause

The reader owns one fixed outcome and can keep an activation open while its work advances. The skill defined partial as actionable, but did not address a mixed boundary where one genuine parent decision made the agent return an otherwise immature candidate.

## Revision

Require the task to identify the Plan Slice action enabled and finish all other locally actionable candidate work before returning partial. A real parent decision does not make unrelated local work returnable. Later returns carry new evidence and the resulting disposition without replaying unchanged proof.

## Evaluation

This should remove progress-checkpoint and mixed-maturity callbacks while preserving genuine partials that expose a decision or correction boundary. It does not extend task scope or move a parent-owned decision into the Step.

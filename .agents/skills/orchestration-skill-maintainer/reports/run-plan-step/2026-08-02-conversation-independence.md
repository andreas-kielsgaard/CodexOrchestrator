# Plan Step conversation independence

## Observation and theory

The user clarified that separately addressable implementation work should independently discover how to resolve its fixed assignment rather than read parent, peer, or earlier conversations. The worker role had a stable scope and callback boundary but did not state what sources should ground its work.

## Revision

The Plan Step now grounds work in its self-contained assignment, current repository or worktree, and authoritative artifacts. It treats conversation ids only as routing addresses and does not use other conversations to reconstruct context or borrow work.

## Evaluation

This keeps the worker independent without withholding the scope, authority, acceptance criteria, artifact locations, or callback route it needs to complete its assignment.

A fresh read-only Plan Step test independently derived its investigation route from the fixed assignment, current worktree, DTO artifacts, consumers, and tests. It treated the parent and earlier worker conversations as outside its evidence sources and made no task or repository change.

# Agent interface loading

## Observation and theory

The general interface skill was discoverable, but the ad-hoc executor did not load it before selecting Computer Use. Discovery alone was therefore insufficient to make the preference reliable across Plan Steps.

## Revision and evaluation

Every ad-hoc Plan Step now loads `$agent-interface-first` when desktop automation is a plausible route. The detailed tool-shaping policy remains in that skill rather than being duplicated in the role.

# Plan Step profile application

## Observation

Planning usually recorded explicit Plan Step profiles, but the Slice-level launch evidence showed that selected settings can be lost when creation relies on host defaults. A visible assessment is therefore insufficient without creation-time application evidence.

## Reader and cause

This reader instantiates the ready Plan Steps. Its earlier wording said to apply the profile but did not explicitly require both creation fields or compare the resulting task profile before delivering the assignment.

## Revision

Apply both selected fields in each task-creation call and compare the host-evidenced result with the intended profile before handoff. Treat omission or mismatch as a routing boundary.

## Evaluation

This enforces the Slice Plan's calibration without asking the launcher to reinterpret it. It prevents silent default inheritance while leaving selection judgment with the Plan Slice conversation.

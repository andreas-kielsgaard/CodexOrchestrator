# Provisional Epic Runner

Status: created. No Epic Runner harness or start-Sprint MCP action is claimed available.

## Trigger

The proposal makes the first meaningful Epic Runner behavior selecting and requesting the first Sprint through an application-owned action.

## Why adjacent skills are insufficient

`epic-planner` chooses development Sprints before this runtime exists. `sprint-planner` operates inside one selected Sprint. The older `orchestration-root` models manual root coordination.

## Wording and expected effect

The skill keeps Epic judgment with the runner while leaving prompt construction, session creation, monitoring, result routing, and transition recording to the application. It favors autonomy within explicit authority and forbids child-session polling.
